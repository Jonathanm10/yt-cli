# Code of Conduct

## Our standard

Please be respectful, constructive, and professional in issues, discussions, and pull requests.

Examples of positive behavior:
- assuming good intent
- giving actionable feedback
- welcoming contributors with different experience levels
- focusing critique on code and ideas, not people

Unacceptable behavior includes harassment, personal attacks, discrimination, and repeated disruptive conduct.

## Enforcement

Project maintainers may remove, edit, or reject contributions and comments that do not align with this standard.
